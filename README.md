# ☁️ Ay File Host v3

Render-এ শুধু হোস্টিং, ফাইল থাকে আপনার **টেলিগ্রাম গ্রুপে**। Render-এর ডিস্কে কিছুই জমে না।
লিংক: `https://your-app.onrender.com/f/123-a1b2c3d4e5/photo.jpg` — শেষে সবসময় আসল ফরম্যাট।

## v3-তে কী নতুন
| সিস্টেম | বিবরণ |
|---|---|
| **লগইনে কোনো লক নেই** | ভুল পাসওয়ার্ড যতবার খুশি দেওয়া যায় — ব্লক/লক/টাইমআউট কিছুই হয় না, শুধু "পাসওয়ার্ড ভুল" দেখায় |
| **পাবলিক API: `/upload`** | `https://আপনার-সাইট.onrender.com/upload` — যেকোনো HTML, ওয়েবসাইট, অ্যাপ, স্ক্রিপ্ট থেকে ব্যবহারযোগ্য (CORS চালু)। সাথে `/list`, `/delete/<id>` |
| **ব্যাকআপ কোড** | সেটিংস → ব্যাকআপ। সব তথ্য (বট টোকেন, API ID/Hash, গ্রুপ আইডি, পাসওয়ার্ড, লিংক সিক্রেট, API কী…) এক এনক্রিপ্টেড কোডে। কোডটি টেলিগ্রাম গ্রুপেও রাখা যায়। নতুন সার্ভারের লগইন পেজেই "ব্যাকআপ থেকে রিস্টোর" |
| **একসাথে অনেক ফাইল** | প্যানেলে একবারে যত খুশি ফাইল/ছবি/ভিডিও (সমান্তরালে), Ctrl+V পেস্ট, সব লিংক একসাথে কপি, ব্যর্থগুলো আবার চেষ্টা। API-তেও এক রিকোয়েস্টে একাধিক ফাইল |
| আগের সব সিস্টেম | বট টোকেন/API ID/Hash/গ্রুপ আইডি প্যানেল থেকে বদল, Render API সিঙ্ক, হেলথ চেক, লগ, রিস্টার্ট ইত্যাদি অক্ষত |

## সেটআপ (৫ মিনিট)
1. GitHub-এ আপলোড → Render → New → **Web Service** (Build: `pip install -r requirements.txt`, Start: `python server.py`)
   - Environment: `PYTHON_VERSION=3.11.9` ও **`ADMIN_PASSWORD=<আপনার পাসওয়ার্ড>`** (প্রস্তাবিত)
2. সাইট খুলে লগইন → **সেটিংস → টেলিগ্রাম**-এ API ID/Hash, বট টোকেন, গ্রুপ আইডি দিন (বটকে গ্রুপে অ্যাডমিন করুন: Post, Delete, Pin)
3. **সেটিংস → সার্ভার**-এ Render API Key দিন (সেটিংস স্থায়ী থাকবে)
4. **সেটিংস → ব্যাকআপ** থেকে ব্যাকআপ কোড বানিয়ে নিরাপদ জায়গায় রাখুন

## পাবলিক API
কী আছে প্যানেলের **API** ট্যাবে। কী দেওয়ার উপায় (যেকোনো একটি): `X-API-Key` হেডার · `?key=…` · `Authorization: Bearer …` · ফর্মের `key` ফিল্ড (ফাইলের আগে)।

```html
<!-- একসাথে অনেক ফাইল/ছবি -->
<input type="file" id="f" multiple> <button onclick="up()">আপলোড</button>
<script>
async function up() {
  const fd = new FormData();
  for (const f of document.getElementById("f").files) fd.append("file", f);
  const r = await fetch("https://আপনার-সাইট.onrender.com/upload?key=API_KEY", {method: "POST", body: fd});
  console.log(await r.json());   // {"ok":true,"count":N,"files":[{"id":..,"name":..,"link":..}, ...]}
}
</script>
```
```
# একটি ফাইল (raw)
curl -X PUT "https://…/upload" -H "X-API-Key: KEY" -H "X-Filename: a.apk" --data-binary @a.apk
# অনেক ফাইল
curl -X POST "https://…/upload?key=KEY" -F file=@a.jpg -F file=@b.png
# তালিকা / ডিলিট
curl "https://…/list?limit=30" -H "X-API-Key: KEY"
curl -X DELETE "https://…/delete/123" -H "X-API-Key: KEY"
```
- `?format=text` দিলে শুধু লিংক ফেরত আসে।
- ভুল/কী না থাকলে `401`। **ওপেন API** (API ট্যাবের সুইচ) চালু করলে কী ছাড়াই আপলোড হয় — ডিফল্টে বন্ধ, কারণ তখন লিংক জানা যে কেউ আপনার টেলিগ্রামে ফাইল তুলতে পারবে।
- মাল্টিপার্ট (ফর্ম) আপলোডে প্রতিটি ফাইল টেলিগ্রামে পাঠানোর আগে সার্ভারের অস্থায়ী ডিস্কে নামে এবং পাঠানো হলেই মুছে যায়। রো (PUT) আপলোড সরাসরি স্ট্রিম হয়।

## ব্যাকআপ ও রিস্টোর
- ফাইলগুলো আসলে টেলিগ্রাম গ্রুপেই থাকে; সার্ভার মুছে গেলে হারায় শুধু সেটিংস ও **লিংক সিক্রেট** (যা ছাড়া পুরোনো লিংক চলে না)। ব্যাকআপ কোডে এগুলো সবই থাকে।
- **রিস্টোর:** নতুন Render সার্ভিস বানান → সাইট খুলুন → লগইন পেজের নিচে "ব্যাকআপ কোড আছে? রিস্টোর করুন" → কোড + পাসফ্রেজ। সার্ভার নিজে টেলিগ্রামে কানেক্ট হয়ে সব সেটিংস ও লিংক ফিরিয়ে আনবে। (`ADMIN_PASSWORD` দিয়ে ডিপ্লয় করলে আগে সেটা দিয়ে লগইন করে সেটিংস → ব্যাকআপ থেকে রিস্টোর করুন।)
- পাসফ্রেজ ছাড়া কোড খোলা যায় না, আর পাসফ্রেজ হারালে কোডও অকেজো — দুটোই সংরক্ষণ করুন। সেটিংস বদলালে নতুন ব্যাকআপ নিন।
- গ্রুপে পাঠানো ব্যাকআপ ফাইলটি (`ayhost-backup.txt`) ফাইল তালিকায় দেখায় না; টেলিগ্রাম অ্যাপ থেকে খুলে কোড কপি করা যায়।
- বটকে গ্রুপ থেকে সরালে বা গ্রুপ মুছলে ফাইলই চলে যায় — ব্যাকআপ তা ঠেকাতে পারে না। অতিরিক্ত রেকর্ডের জন্য ব্যাকআপ ট্যাব থেকে **ফাইল তালিকা এক্সপোর্ট** করুন।

## জেনে রাখুন
- ডাউনলোড-আপলোড Render-এর ব্যান্ডউইথ দিয়ে যায় (ফ্রি প্ল্যানে মাসিক সীমা)। ফ্রি প্ল্যানে ১৫ মিনিট নিষ্ক্রিয় থাকলে সার্ভার ঘুমায় (Keep-alive অপশন আছে)।
- ভুল পাসওয়ার্ডে লক নেই বলে **লম্বা ও শক্ত পাসওয়ার্ড** রাখুন।
